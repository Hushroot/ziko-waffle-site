# Ziko's personal  website

## What is it?
This is my personal website which is talking about things i love the most and my hobbies like games and movies represented in a simple website.

## Features
-Multi-Pages.
-Includes images and styled sections made with HTML and CSS.
-A button that changes the theme of the website made using Javascript.
-A live digital clock.
-An input section that reacts with what the user typing to make him feel he's one of the experince.

## How to use it?
Open the first page and its simple from there.

## What I learned
I learned how to connect Multi-Pages HTML, how to style them using CSS and how to make it interactive using javascripts.
